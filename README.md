# PharmAI (frontend demo)
Open `index.html` in a browser. No build step. Leaflet and Chart.js load from CDN (internet needed for map tiles and charts).
- `js/data.js` mock data (replace with API calls) · `js/components.js` UI helpers · `js/app.js` views and logic
- Portals: switch Consumer / Pharmacy admin / System admin with the header dropdown.
- Forecasts are mock data; there is no backend or ML model.
